# 96孔板颜色判读原型

## 新版：固定拍摄与批次连续判读

1. 将相机放到固定支架，板放到固定板托，保持照明和相机设置一致。开启相机拍摄校准板，也可上传原图。
2. 定位 A1、A12、H12、H1 并检查所有孔圈，点击“保存当前机位”。后续相机预览将显示相同孔圈。软件提供对齐辅助，不能替代支架，也不会自动识别板已放正。
3. 输入批次名称及三个参照孔（默认 B12、C3、A1）。确认参照有效后，点击“采集三色并锁定本批次”。保存的三个实测 RGB/Lab 颜色用于本批次其他组别，而非每张重新取色。
4. 更换板，输入组别，确认方向与孔圈已对齐，点击“拍照并判读”。结果自动加入当前页面的连续记录。上传照片时勾选对齐也可自动记录。
5. 人工修改后，可点击“保存当前复核结果到记录”追加一份复核版本。全部组别 CSV 由 Excel 打开；单张结果可导出 Excel XML。
6. 机位与批次会尝试保存到本机浏览器，建议另下载 JSON 备份。连续记录仅在当前页面，关闭前须导出。改变灯光、相机或曝光后重新校准批次。

相机需要浏览器授权。若本地文件页面无法访问相机，可继续上传照片，或通过本机 localhost 服务打开。当前版本只提供手动确认对齐，没有自动检测板移动。不能保证不同设备拍摄颜色相同。

双击 index.html，用 Edge 或 Chrome 打开。全部图片分析在本机浏览器完成。

1. 上传原始照片，点击“定位四角”，依次点击 A1、A12、H12、H1 的孔中心。这里的名称指实际孔位，底部镜像照片也按实际孔位点击。
2. 检查所有孔圈是否位于孔中央；调整取样半径。四角插值适合接近平行拍摄的板，明显透视或板体弯曲请重拍。
3. B12 为未接种对照、C3 为最低生长变色、A1 为无药生长对照。检查这三个孔及图像质量后，勾选对照确认。
4. 点击孔位可设置人工复核结论和原因。导出保留原判、人工结论和原因。
5. 导入布局 CSV：well,drug,concentration,unit,series。每一 series 是一个独立浓度系列，至少两个不同浓度；同浓度重复孔须一致。可下载模板。
6. 只有确认对照、确认 C3 阈值适用本实验 MIC 终点、布局完整且无异常时才输出候选 MIC。缺少适用折点，始终不作敏感/耐药分类。

Excel 导出为 Excel 可打开的 SpreadsheetML .xml 工作簿，不是 .xlsx。包含逐孔和 MIC 两张表。

指数为沿 B12→A1 的 CIELAB 颜色投影，0/100 是颜色参照，不是菌量百分比。C3 决定阈值，阈值附近、偏离颜色轴、反光过多的孔需复核。当前阈值与质量门限为原型工程参数，未经真实板验证。

## iPhone 安装版

已加入手机触控布局、主屏幕安装配置、离线页面缓存和本机判读记录恢复。iPhone 导出优先打开系统分享面板，可存储到文件。

需把本目录部署到 HTTPS 静态托管地址，然后用 iPhone Safari 打开，点击分享→添加到主屏幕。首次联网加载后，离线缓存成功才可离线重开。直接发送 HTML 文件或访问电脑局域网 HTTP 地址不能作为完整安装方案。上线时保留 index.html、workflow.js、mobile.js、mobile.css、sw.js、manifest.webmanifest 和 icon.svg 的相对目录。

本机记录可能因清理浏览器数据或系统回收而丢失，须及时导出。当前保存颜色及逐孔数据，不持久保存原始照片。尚未经过真实 iPhone 相机、安装、离线和分享测试。网页不能保证锁定 iPhone 曝光及白平衡。

## 双模块版
首页选择支原体颜色分析或细菌沉淀分析。细菌模块每板以 G12 有菌无药、H12 培养基阴性校准，不共享支原体三色。取孔中央与周围环带的亮度对比为沉淀特征，指数阈值默认35、复核带默认8，均待实验验证。支持人工复核及原有导出和浓度布局。两模块的本机记录和机位分开保存。上线需额外上传 modules.js 并更新 sw.js。

## v3 逐孔定位
四角定位仅为粗定位。行列弯曲时，点击24点逐行定位，依次每行1、6、12孔中心，再进行孔壁自动微调；选择孔号并开启单孔调整，可点击真实中心修正。支持2倍/3倍放大和滚动。孔壁自动微调在预测中心附近搜索环形边缘，不依据沉淀暗斑定位；低置信孔列出复核。调整后需重新确认对齐并重新保存机位。保存机位包含96个独立中心，下一张沿用该模板。单张Excel包含逐孔坐标。此功能尚未经过真实iPhone照片准确性验证。上线须上传positioning.js并替换index.html、sw.js。

## v4 整图自动识别
拍照或上传后点击自动识别96孔，不需要先选四角。12列需大致水平，板子完整入镜，倾斜尽量小于14度。以孔壁梯度投票检测圆形候选，再匹配8x12网格；支持板占画面大部分/板较小两档搜索。必须96孔完整匹配且间距合格才应用，不补造缺失孔。检查方向并按需左右/上下翻转孔号，再点击重新分析。定位后仍可放大单孔修正、保存机位。强透视、椭圆变形、反光或复杂背景可能失败，使用24点定位兜底。已通过合成图测试，未声明真实iPhone照片准确率。部署需新增auto-detect.js，覆盖index.html与sw.js，建议上传整个新版包。

## v5 实时预览定位
开启相机→开启实时96孔识别→检查绿色孔圈及A1方向（可翻转孔号）→勾选本张板已对齐→拍照并判读。约每1.5秒加上计算耗时更新一次，不是逐视频帧识别。拍照保存最近识别成功的原始画面与对应孔位，二者严格配对，最长5秒内；请保持板静止。换板需重新开启实时识别。识别失败、板明显移动、方向切换、后台恢复均需重新确认。检测只做孔壁，不判断培养有效性。手机性能和真实设备交互尚需验证。

## v8 批次工作流
顶部新建或选择批次→拍照并识别/对齐→直接拖动孔圈调整→从图片选择三个参照孔（或输入孔号）→保存参照色→同批次连续拍照→导出当前批次CSV（Excel可打开）。已校准批次锁定三个孔号和颜色，重新打开可从批次列表载入。拖动孔圈会清除当前照片人工判读并重新分析，之后需确认对齐。批次和结果保存在当前浏览器，请导出备份。细菌模块仍逐板用G12/H12沉淀对照，不使用颜色三参照。

## v9 拍照后自动识别
取消固定孔圈及实时找孔。开启相机→拍照并自动找孔→自动生成96孔圈并初步判读→拖动修正→确认对齐→保存结果。照片上传同样自动找孔；不沿用旧机位。未完整识别96孔时不自动应用定位，提示重拍或手动定位。保留批次三色与批量表格导出。

## v10 横向拍摄与估算孔圈
相机区域3:2横向显示，拍照按同一中央区域裁剪，请完整放入板子。上传照片保留原画幅。拍照后自动找孔，失败也生成96个独立可拖动孔圈（橙色表示估算，不表示识别成功）。逐个拖动中心并检查方向，确认对齐后才允许有效判读。支持放大及手动重定位，未确认时结果待复核。真实iPhone取景和拖动仍需实机验证。

## v11 组别保存
取消四角、24点和单孔判读复核面板；保留直接拖动孔圈。结果下方唯一保存按钮为保存到当前组别。可输入组别名称，留空自动编号。保存后显示当前批次唯一组数；同批同名组别替换前确认，不重复计数。批次切换和重新打开后从本机记录统计。表格导出保留。

## v12 批次默认确认
移除孔位方向确认勾选项；分析时按批次默认确认，拖动后无需重复确认。估算孔圈仍显示橙色提示，自动判读按当前圈位计算。记录标注alignmentMode=batch-default。保存组别、参照有效性和MIC终点规则不变。
